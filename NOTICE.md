# Repository status and reuse

This is an author-controlled private research repository. No additional code,
data or documentation reuse license is granted by this release. Public release
and licensing need the authors' approval. Third-party dependencies retain their
own licenses; see [THIRD_PARTY_NOTICES.md](docs/THIRD_PARTY_NOTICES.md).

The data bundle preserves original scientific records and private execution
metadata. Keep the repository and its release assets private until a separate
public-release review is complete. Missing actual-executor provenance remains
unknown; logical node names are not substituted for it.

The manuscript repository is separate. This package contains experimental result
reproduction, not the manuscript, review correspondence or architecture diagrams.
The publication channel is GitHub only. No Zenodo record or DOI is used.
